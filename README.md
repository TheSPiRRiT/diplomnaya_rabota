# Модуль автоматизации складского учёта

Дипломный проект: модуль для автоматизации процессов учёта 
на складах предприятия по продаже осветительных устройств.

## 🎯 Задача

Предприятие вело учёт складских операций вручную (Excel + бумажные 
журналы). Цель проекта — разработать модуль, который автоматизирует 
приёмку, отгрузку и инвентаризацию товара, а также формирует отчёты 
по остаткам.

## 🛠 Стек

- **Язык:** C# 
- **БД:** MS SQL Server
- **IDE:** Visual Studio 2022
- **Библиотеки:** Entity Framework 6.2.0 

## 🗄 База данных

В репозиторий не включён файл базы данных (.mdf/.bak), так как он не предназначен для системы контроля версий. 
Структура базы данных полностью описана в модели Entity Framework: `bd.edmx`
Чтобы развернуть базу данных:
1. Откройте решение в Visual Studio.
2. Дважды кликните по файлу `*.edmx`, чтобы открыть дизайнер.
3. Нажмите правой кнопкой мыши на свободном месте диаграммы и выберите **Generate Database from Model...** (Создать базу данных по модели).
4. Следуйте мастеру, выберите подключение к вашему MS SQL Server.
5. Мастер сгенерирует SQL-скрипт. Сохраните его или выполните сразу.
6. После создания базы данных запустите приложение.
